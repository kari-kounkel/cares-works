Mission & values

What we stand for.

The values that shape every job that leaves the shop.

Value 1: Locally owned matters.

Every dollar you spend here stays in Minneapolis — payroll, taxes, suppliers, community. That’s not marketing. It’s just how independent shops work.

Value 2: Union labor built this.

We print with the union bug. We support union locals. We’re opening a dedicated union shop this fall.

Value 3: Nonprofits get priority.

Faster turnarounds, better pricing, and a real partnership program for the organizations doing the work that matters.

Value 4: Craft over speed.

Fast is important. But right is important-er. Every job gets a real pre-press review before it hits the press.
