Teams & Allocations

Each team gets money set aside by leadership. Steward subtracts what's been spent and shows what's left — so you never have to add up accounts by hand again. Click a team to see the detail behind its number.

Operating teams get a yearly amount set aside (Left = Set aside − Spent). Restricted teams (like a Building Fund) are separate pots that carry over and only grow from designated gifts (Left = Opening + Gifts − Spent). Mark the type when you add a team — most teams are Operating.

Import spending from QuickBooks

Pull each team's spending straight from a QBO report — so you never select accounts one-by-one again.

In QuickBooks Online: go to Reports → Profit and Loss by Class (or by Tag / Location), set your date range, then Export (Excel or CSV) — or just open it, select all, and copy. Bring that here. Steward reads the totals for each class and turns them into your teams. Nothing is uploaded — it's read right here in your browser.
